Abstract

Current evaluations of Omni-MLLMs rely on isolated tasks without examining the relationships between them, limiting deeper assessment of audio-visual capabilities. We propose AVI-Bench, a comprehensive evaluation framework built around three cognitively grounded stages—Perception, Understanding, and Reasoning—plus the Primitive Sensation (PriSe) extension for unfamiliar-domain evaluation. The benchmark contains 5,864 samples over 14 tasks, evaluated with 13 metrics and summarized through a four-level AVI taxonomy.

Our findings reveal that reasoning abilities are fundamentally constrained by perception and understanding capacities, and that current systems perform poorly in generalization tasks across different domains.

Benchmark Overview

Evaluation Stages

Perception Identifying and localizing audio-visual elements

AMIC — Audio Multi-Instance Classification

Q: Identify the categories of sound-emitting objects and how many instances of each category are making sounds.

A: {"car": "1"}

VMIC — Visual Multi-Instance Classification

Q: Identify the categories of visible objects and how many different instances of each category are visible.

A: {"flower": "5", "tree": "5"}

AVL — Audio-Visual Localization

Q: Generate the bounding-box of sound-emitting instances in the given image with the help of the given audio.

A: {"tuba_1": [153, 4, 107, 210], "tuba_2": [323, 57, 73, 155]}

AVM — Audio-Visual Matching

Q: Are the contexts of audio and visual content matching?

A: no

Understanding Cross-modal retrieval and semantic comprehension

VAR — Visual-ref Audio Retrieval

Q: Based on the given image as a reference, identify which sounds in the provided audio list contain the objects corresponding to the image.

A: Index list of matching audio clips

AVR — Audio-ref Visual Retrieval

Q: Based on the given audio as a reference, identify which images in the provided image list contain the objects corresponding to the sound.

A: Index list of matching images

AVC — Audio-Visual Captioning

Q: Please describe what you see and hear in a single sentence based on the given audio and video.

A: "A baby is laughing and smiling while her mother is lying down next to her, talking to her."

Reasoning Complex inference and hallucination detection

AVH — Audio-ref Visual Hallucination

Q: Is the car visible in the video?

A: yes

VAH — Visual-ref Audio Hallucination

Q: Is the car making sound in the audio?

A: yes

AVQA — Audio-Visual Question Answering

Q: Is there a voiceover?

A: yes

AVLG — Audio-Visual Language Grounding

Q: Segment the object in the given frames based on the given text reference. Reference: The sounding object near the man.

A: {"frame_0": [705, 359, 353, 229], ...}

Primitive Sensation Out-of-domain fundamental sensory evaluation

Three PriSe tasks: ASQA, VSQA, and AVSQA — designed to probe primitive sensory abilities on low-semantic, out-of-distribution stimuli.

ASQA — Audio Sensation Question Answering

Q: How many beats can you hear?

A: 3

VSQA_I — Visual Sensation QA (Image)

Q: Is the background of the given image clear?

A: no

VSQA_V — Visual Sensation QA (Video)

Q: Which object's area in the video has not changed?

A: square

AVSQA — Audio-Visual Sensation QA

Q: Which object produces sound first?

A: cube

Toward Human-like Audio-Visual Intelligence

AVI-Bench will be continuously maintained as a long-term, open community resource. We evaluate model capabilities along four adaptive dimensions:

Task Adaptive

Models demonstrate effective overall performance across a wide range of audio-visual tasks.

Modal Adaptive

Models demonstrate strong performance on both audio and visual modalities.

Stage Adaptive

Models show strong performance on both perception and understanding for better audio-visual reasoning.

Domain Adaptive

Models show human-like domain generalization across diverse scenarios.

Getting Started

# Setup
conda create -n avibench python=3.11 -y
conda activate avibench
pip install -r requirements.txt

# Configure your OpenAI-compatible API gateway
export OPENAI_API_KEY=...
export OPENAI_BASE_URL=...
export DATA_ROOT=/path/to/AVIBench_data_release/levels

# Quick smoke test (5 samples per task)
python test_all_tasks.py

# Full pipeline
bash run_all.sh                         # inference
cd auto_format && python run.py        # refine
cd ../eval && python eval.py            # evaluate
