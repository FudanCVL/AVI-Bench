About AVI-Bench

Benchmarking Omni-MLLMs across Human-like Audio-Visual Intelligence.

AVI-Bench organizes audio-visual evaluation around three cognitive stages—Perception, Understanding, and Reasoning—and adds Primitive Sensation for unfamiliar-domain evaluation. The benchmark contains 5,864 samples across 14 tasks, measured with 9 metrics.

Quickstart

Evaluate a model in three steps

# 1. Setup
conda create -n avibench python=3.11 -y && conda activate avibench
pip install -r requirements.txt

# 2. Configure your OpenAI-compatible gateway
export OPENAI_API_KEY=... OPENAI_BASE_URL=...
export DATA_ROOT=/path/to/AVIBench_data_release/levels

# 3. Inference -> Refine -> Evaluate
bash run_all.sh
cd auto_format && python run.py && cd ..
cd eval && python eval.py --models gemini-2.5-pro
