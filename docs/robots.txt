# Policy
# ------
#   * Conventional search engines (Googlebot, Bingbot, DuckDuckBot,
#     Yandex, Baidu, ...) -- ALLOWED.  This site is intended to be
#     discoverable from web search.
#   * AI-search retrieval agents that fetch pages at query time and do
#     NOT add the page to a training corpus (OAI-SearchBot,
#     ChatGPT-User, Claude-SearchBot, Perplexity-User, Google AI
#     Overviews via Googlebot, ...) -- ALLOWED.  These power AI chat
#     citations and recommendations.
#   * Training crawlers operated by AI companies that scrape pages
#     into training corpora -- BLOCKED below.
#
# The AVI-Bench dataset itself is licensed under the AVI-Bench Data
# Use Policy v1.0, which prohibits using the dataset to train,
# fine-tune, distill, or align any machine-learning model.  This file
# is one of three complementary measures (LICENSE, HTML meta directives,
# robots.txt) and does NOT by itself confer permission to ignore the
# Data Use Policy.
